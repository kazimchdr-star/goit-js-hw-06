# JavaScript Ödev 6

`this`, sınıflar ve özel alanlar ile ilgili üç JavaScript görevi.

- `js/task-1.js`: Kullanıcı hesabı, indirim ve sipariş yönetimi.
- `js/task-2.js`: Özel `#items` alanıyla depo yönetimi.
- `js/task-3.js`: Özel `#value` alanıyla string birleştirme.

Projeyi yerel bir HTTP sunucusunda açın (örneğin VS Code Live Server).
`index.html` sayfasında geliştirici konsolunu (F12) açarak örnek çağrıların
sonuçlarını görebilirsiniz.
